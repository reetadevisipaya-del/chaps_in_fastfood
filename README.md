# 🍟 Chaps-In Fast Food | Chandigarh (Legend Since 1994)

The official modern web application for **Chaps-In Fast Food** (formerly *Chaplin Fast Food*, Sector 34-C, Chandigarh). Built with React 19, Vite, Tailwind CSS, and direct WhatsApp ordering integration.

## ✨ Features

- **Direct WhatsApp Ordering:** Automatically compiles customer name, phone, delivery address, payment mode, and cart item breakdown into a clean formatted message dispatched to the Sector 34 kitchen (+91 86998 22549).
- **Authentic Full Menu & Prices:** 100+ authentic dishes including Legendary Kurkure Momos, Afghani Momos, Cheese Naan with Gravy, Butter Chicken, Chaplin Special Chowmein, Combos for 1, Platters, Thalis, and Cheese Foam Boba Tea.
- **Smart Delivery Charges:** Real-time delivery calculations (Free delivery in Chandigarh above ₹500, Mohali above ₹700, or self-pickup).
- **Responsive Fast-Food Design:** Playful modern aesthetic using Fredoka and Plus Jakarta Sans typography, tomato orange (#F4512C), butter yellow (#FFD966), warm cream (#FFF8EA), and dark chocolate (#29211E).
- **Social & Foodie Hub:** Direct links to their official Instagram ([@chaps_in_fastfood](https://www.instagram.com/chaps_in_fastfood?exln=dzA0dXJtaDRvYXR1)) and Zomato store ([Chaps-In on Zomato](https://zomato.onelink.me/xqzv/grkmtcli)).

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deployment Settings (Netlify)

- **Build command:** `npm run build`
- **Publish directory:** `dist`
- **SPA Routing:** Configured via `_redirects` and `netlify.toml`
